# MLauncher

Launcher Android in stile HyperOS con colori e widget Material You (Android 12 o successivo).

- Home con griglia regolabile, dock, cartelle, tremolio in modifica, trascinamento tra pagine
- Cassetto app oppure tutte le icone in Home (a scelta nelle impostazioni)
- Effetti di cambio pagina, animazione di disinstallazione, icone Material You
- APK compilato da GitHub Actions e pubblicato nelle Release
